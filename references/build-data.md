# 建设与数据

从材料确定角色、日常任务、主工作区和两项关键交互，在已有建设计划写一小段。功能与布局服从对象：图像检测用图像检视/叠层/局部复核，事件调查用时间关联，调度用资源占用/任务进度。所有按钮真实可用或准确说明合法不可用状态，不用空模块或通用CRUD替代核心技术。

只抽取一次材料并保存source_trace：全部段落/原式OMML/原图/流程/例子对应实际函数/API/持久化/页面/导出/检查，输入与输出区分，记录符号、单位、键、时序、阈值和分支。原式和例子有出入保留具体差异及实现依据。材料没有公式时不发明。核心方法进入真实消费路径，不以未调用代码、注释或硬编码结果充数。训练/推理仅在材料要求时实际实现；未有权重/训练运行/现场数据必须准确记录限制，不虚称效果。

同一次high建设先真实运行技术核心、第二个合法对象、重复状态操作和关键拒绝反例，确认身份、版本及终态；正常与非法输入均从最终消费API进入，归一化后的真实返回值用于分支、落库和贡献，不丢弃校验结果。之后扩量及录制。源有相应机制时覆盖：不可变快照与恢复闭包、接收/准备/发布区分、摘要精度一致、历史/当前/未来回执、权威起点与非默认参数、已知可行解/小规模穷举对照、源定双门槛、训练/推理同空间同单位、上游状态实际传递。未知或限时未搜到不能说物理无解。源没有对应机制则如实不适用，不硬套别案规则。

页面/列表/详情/统计/日志引用同对象同版本；状态成功后保留筛选、排序和合法分页，已关抽屉不被迟到请求打开。中文错误提示、空结果、网络失败、重复点击、角色切换、降权后合法认证、权限、服务端有限值/范围校验适用核验。部署具备迁移/初始化、健康检查、生产构建、启动停止、备份恢复；凭据外置，无公开固定管理员口令。缺目标服务器则只声明本机可部署，不擅自上线。

检索同领域开源仓库及正式数据，至少核一个适用且能实际取得的入口，尽量比较两种来源；URL、版本、访问时间、许可、下载哈希、字段单位和适配决定内部保存。介绍页不算已取得原始数据。不可取得如实记限制，不捏造成功。图像输入保留真实授权/许可及原图hash；原始标注仅用于独立评估，算法预测不可从GT直接映射。

data-plan写实体数/时间范围/频率/事件/目标/关系/验收；新案无真实旧基线用空baseline。高频项目可从30–90天、多对象、十万行级规划；业务记录可从万行级起步，合理较小体量给业务/硬件原因。已有主要明细以清洗后有效量约2倍规划，低于该起点具体说明；维表/汇总无需逐表翻倍。确定性领域脚本扩展，保种子/参数/约束/噪声，不能复制行或独立随机列凑量；公开输入与扩充性质明确，不改称实测。

CSV白名单选业务实体、主记录、事件、关键结果及必要汇总；剔除空表、重复分片、调试/中间表。数据量以实际有效键统计，核对象数、时间跨度、事件、PK/FK、去重、缺失、范围/分布/相关性、守恒/约束及派生字段完整重算。训练类按时间/实体隔离防泄漏。系统从这些交付CSV真实初始化，API/Web导出与初始化一致。

输出CSV为UTF-8 BOM，保字段顺序、精度、时间、空值、行序。只整列删除生成/来源元数据及精确同义列，不误删“生成时间”业务列，不自动删改普通单元格。文件名/列名/所有文本值不得含真实或编造地名/公司名/人名；中性稳定ID跨表和Web保持一致，映射内部留存。data_preflight只认schema/已知名和hash审阅，不是完整NER；high实际检查文本并保存当前hash name_review。ui-policy.json及package_policy.py禁词适用于代码/Web/交付CSV，不能用转义/拼接藏词，不能删除内部真实出处或改称实测。必要第三方法律署名保留并逐项说明；LICENSES不是藏说明豁免。

所有首次语义核验由实际领域命令、输入/实现hash、断言和日志支持，结构/FK/API成功不能证明业务正确。一次足量且清洗通过CSV保持完成；后续新算法用内部隔离数据验证，只核成品本身与既有通过事实。只有CSV明确错误才定向处理。视频也是一版真实合格后复用；主体流程/媒体自身实质问题才定向重录。不要用旧通过结论证明新算法。
